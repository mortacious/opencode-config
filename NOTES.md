# Session ledger - speed tuning of the fusion config

## Goal
Cut typical task wall time by trimming mandated overhead without weakening correctness gates.

## Decisions
- Reviewer audit is now conditional: run for non-small changes (>2 files, logic-bearing code, permission/agent edits, provider changes, security/secret-adjacent); small changes are self-verified by the primary.
- Reviewer never re-runs test suites: it treats the sidekick's pasted raw verification output as primary evidence; un-backed claims and evidence gaps go into FINDINGS, not workarounds. (Also sidesteps npm test in this repo, which could not be exercised during this round.)
- Light prompt slimming (build.md token economy, reviewer plan-review section, plan.md duplicates) for faster generation.
- Sidekick model swapped to opencode-go/mimo-v2.6-flash as an experiment; revert if edit quality regresses (AGENTS.md updated to match).
